## 1. Что такое Mimose

Мультиисточниковый музыкальный комбайн: объединяет Яндекс Музыку, YouTube/YT Music, VK, Deezer, SoundCloud, Spotify, Tidal в «одном тёмном музыкальном пространстве». Сервер `api.mimose.fun/api/v3` + `relay.mimose.fun`, оплата веб-эквайрингом (не StoreKit). Аккаунт обязателен (auth/register, google/telegram OAuth). Все премиум-гейты исполняются **серверно**.

## 2. Тарифы

- **Free**: базовый поиск/плеер, ограниченное качество, квоты ИИ (пример: «Ассистент входит в подписку Beyond», «Осталось запросов», `quota_exceeded`, `aiQuota: dailyLimit/monthlyLimit`).
- **Plus** (150 ₽/мес, 399/649/999 ₽ за 3/6/12 мес): автоматический перевод текстов на русский; импорт/прослушивание VK; Deezer в FLAC; пользовательские пресеты эквалайзера; управление скоростью воспроизведения; премиум-бейдж; клипы 4K в полноэкранном плеере; аннотации к тексту; поиск трека по тексту.
- **Beyond** (добавка к Plus): ИИ-ассистент («понимает, что вы слушаете, включает похожие треки, составляет плейлисты под настроение, управляет приложением, объясняет смысл треков, рассказывает биографию артистов»), генерация плейлистов по описанию, миксы, память диалога (`/beyond-beta/ai/memory`), экспорт данных Beyond, семейная подписка, облачные локальные треки (до 500 МБ/файл: MP3, FLAC, M4A, AAC, WAV, OGG, Opus), Shazam-распознавание.

## 3. Полная карта функций (по эндпоинтам и строкам UI)

### Каталог и источники
- Единый поиск по всем источникам: `/search`, `/spotify/search`, `/yandex/search`, `/ytmusic/search`, `/deezer/`, `/tidal/search`, `/soundcloud/`.
- Чарты и новинки: `/yandex/chart`, `/yandex/new-releases`, `/search/trending`, `/top-tracks`, «Топ треков Mimose», «Самые популярные треки прямо сейчас».
- Страницы исполнителя/альбома: `/artists/`, `/albums/`, `monthlyListeners`, дискография, «Популярные треки».
- Радио по треку/станции: `/station`, `/wave/radios`.
- Release Radar: `/discovery/release-radar` — новинки любимых артистов.
- Жанры: `/genres`, `/discovery/genres`, предпочтения жанров при онбординге.

### Плеер
- Мини-плеер и полноэкранный плеер, очередь, перемешивание, повтор (один/очередь/выкл), перемотка.
- Crossfade «Плавный переход между треками» (+ режим «плеер переключится в конце текущего трека»).
- Эквалайзер (кривая, полосы, «Эквалайзер Pro»/Studio), **кастомные пресеты** и **per-track пресеты** (`/eq/presets`, `TrackEqualizerStore`), превью пресета.
- Скорость воспроизведения (tempo, «Пониженный темп», через time-pitch).
- Таймер сна (до конца трека / один трек / вся очередь / выкл).
- FLAC/Lossless: `/get-flac/`, `HI_RES_LOSSLESS`; проверка FLAC для Яндекс Музыки и Deezer; «Если FLAC недоступен — обычное качество».
- Клипы/видео 4K в полноэкранном плеере (`video4k`, `/shorts/`).
- Распознавание музыки (Shazam): `/shazam/recognize`, «Запишите 10 секунд музыки рядом».
- Закреплённый трек в профиле (`/profile/pinned-track`), свайпы треков, лайк/дизлайк (`/reactions`, `/tracks/disliked`, дизлайк исключает из рекомендаций).
- Now Playing: «Уведомление и управление системным плеером».
- Облако своих файлов: `/library/local/*` (upload, stream-url, quota, preflight).

### Тексты песен
- Синхронизированные тексты (`syncedLyrics`, `LyricSegment`) через **LRCLIB** (`/lrclib/get`, `/lrclib/search` — публичный открытый API) + `/v1/lyrics*`.
- Автоперевод текста (`/lyrics/translate`, `translateLyrics`).
- Аннотации Genius: `/genius/lyrics`, `/genius/artist`, `lyricsAnnotationsProvider`.
- Поиск трека по строчке текста: `searchLyrics`, «Находите трек по строчкам, даже если не помните название».

### My Wave / рекомендации
- `/wave/recommendations`, `/wave/state`, `/wave/mode`, `/wave/event`, `/native/wave/v2/events/batch` (батч-отправка событий прослушивания), миксы `/native/wave/v2/mixes`.
- Ежедневные миксы, «Новые треки для вас», подбор по вкусу, поиск похожих треков, «Больше новых треков и исполнителей».
- Лайки/дизлайки и история влияют на рекомендации; дизлайк-лист с возможностью вернуть трек.

### Библиотека и плейлисты
- Любимые треки, плейлисты (создание/редактирование/удаление), совместные плейлисты (`/collaboration`, приглашения, роли), сортировка, reorder (`/reorder`), участники.
- Импорт плейлистов по ссылке: `/playlists/import-url` (Spotify/Deezer/Яндекс), `/playlists/import-vk-audio`, прогресс импорта. Ограничение: «Это ссылка на альбом. Сервис поддерживает импорт только плейлистов».
- Загрузки (офлайн): `/downloads-v1`, «Нажмите Скачать в плеере», скачанные плейлисты, «Очистить все загрузки?».
- История: `/recent-tracks`, `/plays`, `/sessions/`.
- Статистика: `/stats/me`, `/stats/user/`, «любимых артистов и недавние треки», слушатели за месяц.
- Достижения, теги профиля, аватар/баннер (баннер — Plus).

### Социальное (в нашей версии — не приоритет)
- E2E-мессенджер с отправкой треков, живые комнаты/стримы друзьям, друзья/presence, сообщество (leaderboard, плейлисты сообщества), комментарии к новостям.

### AI «Beyond» (endpoints: `/beyond-beta/ai/*`)
- Чат-ассистент с действиями: играть/пауза/следующий, repeat, поиск трека, «Найди треки, похожие по звучанию», биографии артистов, объяснение смысла треков.
- Плейлист по описанию (`/beyond-beta/ai/playlist`), миксы (`/ai/mix`), совместный плейлист со вкусами друга.
- Память, история чата, лимиты квот (daily/monthly), экспорт данных Beyond.
- Статистика по запросу: «Покажи мою статистику: любимых артистов и недавние треки».

## 4. Дизайн-язык Mimose (наблюдения сайта и строк UI)

- Чистый чёрный фон (`#000000`, theme-color), «тёмное музыкальное пространство», минимум хрома.
- Wave-шейдер (`wave.frag`) — живой градиентный фон/обложка волны; «orb» визуал ассистента (BeyondOrb).
- Крупные обложки, карточки со скруглением, компактная навигация («Главная, плеер, моя музыка, сообщество»).
- Шрифты: системные woff2 (вероятно SF/Inter-подобные), сдержанная типографика.
- Состояния: shimmer/skeleton («Не удалось загрузить. Нажмите, чтобы повторить»), пустые состояния с короткими подписями.
- Минимум кнопок: действия спрятаны в «Действия с треком» (контекстное меню 3 точки).

## 5. Ограничения платформ (важно для легальной реализации)

| Сервис | Официальный API | Полн. воспроизведение | Что реализуемо у нас |
|---|---|---|---|
| Apple Music | MusicKit | да, подписчикам Apple Music | поиск, библиотека, playback через ApplicationMusicPlayer |
| Deezer | публичный api.deezer.com (без ключа) | только 30-сек preview без подписки; FLAC — платный контент | поиск, метаданные, чарты, preview-воспроизведение, deep-link, импорт плейлистов |
| Spotify | OAuth PKCE + Web API | через Spotify App Remote / deep-link | OAuth, поиск, библиотека, handoff `spotify:track:` |
| YouTube Music | официального публичного API воспроизведения нет; Data API — только метаданные | нет (ToS/DRM) | поиск через Data API (опц. ключ) + deep-link |
| VK Музыка | audio API закрыт для сторонних (с 2016) | нет | deep-link; импорт — blocked (документируем) |
| SoundCloud | публичный API ограничен, oEmbed открыт | нет | oEmbed-метаданные + deep-link |
| Яндекс Музыка | API закрыт | нет | deep-link (roadmap) |

Mimose получает полные потоки через собственный relay/прокси (`/ytdlp/direct/`, `/soundcloud/hls/`, `/stream/`) — это серверная инфраструктура в серой зоне; мы сознательно не воспроизводим эту схему. Наш принцип: доступно то, что сервис отдаёт легально (официальный API, preview, deep-link), остальное — честный handoff.

## 6. Выводы для собственного приложения (Nocturne)

1. Ядро то же: мультиисточниковый поиск + единая библиотека + плеер + волна, **полностью локально**, без обязательного аккаунта.
2. Все «плюс»-функции делаем бесплатно: перевод (LibreTranslate-адаптер), кастомные и per-track пресеты EQ, скорость, поиск по тексту (LRCLIB), аннотации (локальные заметки + Genius через бесплатный ключ пользователя), FLAC — там, где источник реально отдаёт файл легально (локальные файлы; для стриминга — максимальное доступное качество источника).
3. ИИ-ассистент — локальный интент-движок (без LLM-квот): управление плеером, поиск, плейлисты по описанию, статистика, похожие треки. Честно документируем, что это не LLM.
4. Дизайн: чёрная база, крупные обложки, карточки, компактный таббар, волновой градиент как акцент, аккуратные empty/loading состояния.
5. Социальное (комнаты, мессенджер, семьи) — вне скоупа v1 (roadmap), это требует сервера, которого у нас нет по ТЗ.
