# Nocturne

**Тёмное пространство вашей музыки** — нативный iOS-музыкальный комбайн в духе Mimose: несколько источников в одном минималистичном приложении, персональная волна, полноценный плеер и все «премиум»-функции **бесплатно**.

- Минимальная версия: **iOS 15.0**
- Технологии: Swift, SwiftUI, AVFoundation (AVAudioEngine), MusicKit, SQLite, URLSession, Swift Concurrency, Keychain, MediaPlayer
- Без WebView, без обязательного аккаунта, без сервера, без подписок и квот

## Что внутри

- **Источники**: локальные файлы, Deezer (публичный API + фрагменты), Apple Music (MusicKit), Spotify (OAuth PKCE + Web API), YouTube Music (Data API + handoff), VK/SoundCloud (handoff). Модульная система адаптеров `MusicProvider`.
- **My Wave**: локальный алгоритм рекомендаций (аффинити к исполнителям, лайки/дизлайки, история, свежесть, диверсификация, настраиваемое «открытие новой музыки»), миксы по настроению, радио по треку, автодобор очереди.
- **Плеер**: AVAudioEngine, два голоса для **crossfade**, 10-полосный **эквалайзер** с кастомными и per-track пресетами, **скорость** без изменения тона, таймер сна, фоновое воспроизведение, экран блокировки/Control Center, восстановление сессии.
- **Тексты**: синхронизированные (LRCLIB) с karaoke-подсветкой, **автоперевод** (LibreTranslate), **поиск по строчке текста**, аннотации (Genius + локальные заметки).
- **Ассистент**: локальный интент-движок (RU/EN) — управление плеером, поиск, плейлисты по описанию, статистика. Без LLM-квот.
- **Данные**: всё на устройстве (SQLite), секреты в Keychain, экспорт/восстановление JSON, импорт плейлистов M3U/CSV/JSON и по ссылке (Deezer/Spotify), статистика.

## Быстрый старт

```bash
# macOS (требуется Xcode 15+ и XcodeGen)
brew install xcodegen
xcodegen generate
open Nocturne.xcodeproj
```

Выберите схему **Nocturne** и запустите на симуляторе/устройстве.

## Сборка с Windows

Исходники правятся на Windows и коммитятся в GitHub; Xcode-проект генерируется
**XcodeGen** (файл `project.yml` — источник правды). Сборка и тесты — через
GitHub Actions (macOS runner): `.github/workflows/ios.yml` — Debug build,
unit-тесты на симуляторе, Release build.

Подробнее: [DEVELOPMENT.md](DEVELOPMENT.md), [ARCHITECTURE.md](ARCHITECTURE.md).

## Принципы

1. Все функции бесплатны — никаких подписок, лимитов и премиум-гейтов.
2. Ничего чужого не взламываем: используем только официальные/открытые API; где сервиса нет — честный handoff в оригинальное приложение (ограничения задокументированы).
3. Приватность: всё локально, обязательной регистрации нет.
4. Нативный SwiftUI, никаких WebView.
